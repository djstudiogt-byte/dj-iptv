PUBLICAR DJ-IPTV EN CLOUDFLARE · enlace para tu familia (gratis, 100% navegador)
================================================================================
Sin instalar NADA: ni Node.js, ni terminal, ni Linux. Solo pestañas del
navegador (perfecto para ChromeOS Flex). Resultado: un enlace tipo

        https://tu-iptv.pages.dev

Quien lo abra ve la app, pulsa «Añadir cuenta», mete los datos de su
proveedor Xtream y listo. Funciona en PC, móvil, tablet y Smart TV.

ELIGE UNA DE LAS DOS OPCIONES
-----------------------------
· OPCIÓN A (recomendada): GitHub + Cloudflare Pages. El enlace lleva su
  PROPIO PROXY INTEGRADO: quien lo abre no toca ningún ajuste. ~10-15 min.
  (La subida rápida por arrastrar en Cloudflare NO publica el proxy: lo
  dice su documentación oficial. Con GitHub sí se publica.)
· OPCIÓN B (sin GitHub): arrastrar index.html a Pages + crear un Worker
  con copiar y pegar. ~7 min. Para unir app y proxy se comparte el enlace
  con un pequeño añadido (#proxy=…), paso 3.


================================================================================
OPCIÓN A · GitHub + Cloudflare Pages (proxy integrado, cero configuración)
================================================================================

PASO 1 · Sube los archivos a GitHub (cuenta gratis)
----------------------------------------------------
1.1  Entra en  https://github.com  → «Sign up» (o «Sign in» si ya tienes).
1.2  Arriba a la derecha, icono «+» → «New repository».
     Repository name:  dj-iptv        Visibilidad: Public
     Pulsa «Create repository».
1.3  En la página del repo, pulsa el enlace «uploading an existing file».
1.4  ARRASTRA ahí los archivos  index.html  y  LEEME-PUBLICAR.txt  de esta
     carpeta «publicar». (Si actualizaste la app, usa tu index.html más
     reciente.) Baja y pulsa «Commit changes».
1.5  Ahora la carpeta del proxy. Pulsa «Add file» → «Create new file» y
     escribe este nombre EXACTO (al teclear la barra / GitHub crea las
     carpetas solo):

        functions/api/proxy.js

     Abre el archivo functions/api/proxy.js de esta carpeta con el Bloc
     de notas (o doble clic: se abre en el navegador), copia TODO su
     texto, pégalo en GitHub y pulsa «Commit changes».
1.6  Repite el paso 1.5 con:

        functions/api/cors-check.js

     (pega el contenido del archivo functions/api/cors-check.js).

PASO 2 · Conecta Cloudflare Pages con tu GitHub (cuenta gratis)
----------------------------------------------------------------
2.1  Entra en  https://dash.cloudflare.com  → crea la cuenta (solo correo).
2.2  Menú izquierdo: «Workers & Pages» → «Create application» →
     pestaña «Pages» → «Connect to Git» → «GitHub» → autoriza a Cloudflare.
2.3  Elige el repositorio  dj-iptv  → «Begin setup».
2.4  En «Set up builds and deployments» deja así:
        · Project name:            dj-iptv  (o el que quieras)
        · Framework preset:        None
        · Build command:           (DÉJALO VACÍO)
        · Build output directory:  /
     Pulsa «Save and Deploy».
2.5  En ~1 minuto estarás en línea. Tu enlace sale en el panel:
        https://dj-iptv.pages.dev   (el nombre exacto es el de tu proyecto)

PASO 3 · Comprueba que el proxy vive
-------------------------------------
Abre  https://dj-iptv.pages.dev/api/cors-check  → debe responder:

        {"ok":true,"proxy":"DJ-IPTV","via":"pages"}

Luego abre la app, añade tu cuenta y verás conectar enseguida: la app
detecta SU PROPIO proxy sola (mensaje en consola «proxy integrado
detectado»). A tu familia le pasa igual: abren el enlace y ya.

PARA ACTUALIZAR LA APP MÁS ADELANTE
------------------------------------
En GitHub: «Add file» → «Upload files» → arrastra el index.html nuevo
(sobrescribe) → «Commit changes». Cloudflare lo redespliega solo.


================================================================================
OPCIÓN B · Sin GitHub: Pages (arrastrar) + Worker (copiar y pegar)
================================================================================

PASO 1 · Sube la app a Pages (solo el HTML)
--------------------------------------------
1.1  https://dash.cloudflare.com → «Workers & Pages» → «Create application»
     → pestaña «Pages» → «Upload assets» (Direct Upload).
1.2  Project name:  mi-iptv   →  ARRASTRA solo el  index.html  → «Deploy site».
1.3  Enlace: https://mi-iptv.pages.dev
     (Ya funciona con los proxies públicos automáticos; ahora le añadimos
     tu proxy propio, más fiable y privado.)

PASO 2 · Crea el proxy (Worker de copiar y pegar)
--------------------------------------------------
2.1  «Workers & Pages» → «Create application» → pestaña «Workers» →
     «Create Worker». Nombre:  dj-proxy  → «Deploy» → «Edit code».
2.2  Borra TODO el código de ejemplo. Abre con doble clic el archivo

        worker/dj-proxy-worker.js     (de esta carpeta)

     copia TODO su texto, pégalo en el editor de Cloudflare y «Deploy».
2.3  Te dan una dirección tipo:  https://dj-proxy.tuusuario.workers.dev
     Ábrela en el navegador: debe salir  {"ok":true,"proxy":"DJ-IPTV",…}

PASO 3 · Une la app con tu proxy (elige una forma)
---------------------------------------------------
   a) Para ti: abre tu app → Ajustes → Red → «URL del micro-proxy
      (avanzado)» → pega https://dj-proxy.tuusuario.workers.dev →
      «Guardar» → pulsa «Probar conexión».
   b) Para compartir (recomendada): manda este enlace, que lleva el proxy
      dentro y se configura solo al abrirlo:

      https://mi-iptv.pages.dev/#proxy=https://dj-proxy.tuusuario.workers.dev

      (todo junto, sin espacios; cambia los dos nombres por los tuyos).


================================================================================
COSAS QUE CONVIENE SABER
================================================================================
· GRATIS: el plan gratuito de Cloudflare incluye 100.000 peticiones/día
  en el proxy. Un grupo de familia/amigos no lo agota (una película son
  unos miles de peticiones). Si algún día te quedas corto, el panel te
  ofrece el paso siguiente (de pago).
· PRIVACIDAD: las cuentas y contraseñas de cada usuario se guardan
  CIFRADAS en SU navegador; a tu instancia de Cloudflare solo pasan para
  conectar. Con tu propio proxy (opciones A y B) las peticiones NO pasan
  por servicios de terceros, a diferencia del proxy público.
· VÍDEO: también pasa por tu proxy, con soporte Range (pausar, adelantar
  y retroceder funcionan).
· ACTUALIZAR (opción B): en tu proyecto Pages → «Create deployment» →
  vuelve a arrastrar el index.html nuevo.
· NORMATIVA: si tu proveedor de IPTV prohíbe verlo por web o compartir
  cuenta, respeta sus reglas.
